Репозиторий по взвешиванию при манипуляции для Unitree g1.

Модуль запускается с вашего пк на linux, по проводу. Для корректной работы нужно подключиться по проводу к unitree_g1, узнать имя интерфейса
и записать его в класс UnitreeG1, подробнее см. в репозитории:

https://github.com/unitreerobotics/unitree_sdk2_python

## Зависимости:

1. python 3.10 - советую создать окружение в conda
2. Установить unitree_sdk_py:
```
cd unitree_sdk2_python
pip install -e .
```
3. pip install pin

## Структура проекта:

measure_modules\pinfuncs.py: содержит непосредственно метод взвешивания

measure_modules\unitree_g1: класс unitree_g1 для удобной работы с API робота

measure_modules\move_arms.py: пример работы модуля. Робот выполняет траекторию руками (приподнимает их), и производит взвешивание.
Для работы необходимо запустить робота в обычное состояние, где он стоит на ногах. **Во время выполнения вокруг робота должно быть свободное пространство.**
